# Portal NexaCorp

Laboratório de pentest reunindo os temas trabalhados ao longo do curso. A
aplicação tem múltiplos caminhos de exploração que convergem em um
objetivo final.

Ver [`Instrucoes.md`](Instrucoes.md) para o contexto completo e
[`Requisitos-Relatorio.md`](Requisitos-Relatorio.md) para o que deve ser
entregue e como é avaliado.

## Subindo o ambiente

```bash
docker compose up --build
```

Aplicação disponível em `http://localhost:8084`.
